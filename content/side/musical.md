## 프로젝트 소개
**뮤지컬 배우·극 정보·후기·로그인 시스템을 제공하는 뮤지컬 관리 시스템**입니다. Java JDBC와 MySQL을 연동해, 흩어진 정보를 취합·제공하기 위해 작성했습니다.
## 💻담당 업무
(Java JDBC · MySQL) — MySQL 데이터 및 JDBC 내 검색 기능 담당
- **MySQL–JDBC 연동으로 효율적인 검색·관리 기능 제공**
- **JDBC GUI 활용**
- **MySQL 쿼리문 작성 및 활용**
  - Statement: 정적 쿼리 실행
  - Prepared Statement: 파라미터를 입력받는 동적 쿼리 실행
## 📝프로젝트를 진행하며 배운 점📝
<div class="callout"><span class="ci">💡</span> MySQL과 JDBC 연동으로 프로그램에서 쿼리문을 DB에 전달·수신하는 구조·원리를 파악했습니다. 특히 Statement는 사용자가 고의로 쿼리에 영향을 주는 검색어를 입력하면 오류·보안 취약점이 생길 수 있어, Prepared Statement로 이를 방지했습니다.</div>
